# 🚀 SpaceMath – Gra Edukacyjna

**SpaceMath** to edukacyjna gra mobilna stworzona z myślą o dzieciach, mająca na celu naukę podstaw matematyki poprzez interaktywną zabawę. Gra została zaprojektowana i zaimplementowana jako część mojej pracy licencjackiej na kierunku Informatyka.

## 🎮 Opis gry

Gra oferuje trzy główne tryby rozgrywki:

- **Rysowanie liczb**: Użytkownik rysuje cyfrę odpowiadającą liczbie przedstawionych obiektów, korzystając z podpowiedi.
- **Zliczanie obiektów**: Gracz liczy przedmioty i wybiera prawidłową odpowiedź spośród dostępnych opci.
- **Dodawanie**: Rozwiązywanie prostych zadań dodawania liczb w zakresie od 0 do 10 poprzez przeciąganie prawidłowej odpowiedzi na odpowiednie miejse.

## 📱 Platformy

Gra jest dostępna na następujące platformy:

- iOS
- Android

## 🛠️ Technologie

- **Unity** – silnik gry użyty do stworzenia proektu
- **C#** – język programowania wykorzystany do implementacji logik gry
- **Unity Remote** – użyte do tdo testowania aplikacji

## 🚀 Uruchamianie projektu

1. **Pobierz lub sklonuj repozytorium:**

   ```bash
   git clone https://github.com/GameRuiner/Praca-dyplomowa.git
   ```

2. **Otwórz projekt w Unity:**

   - Uruchom Unity Hub
   - Kliknij "Add" i wskaż folder z projektem
   - Otwórz projekt

3. **Uruchom grę:**

   - W Unity wybierz scenę startową (np. `Menu`)
   - Kliknij przycisk "Play" w górnej części interfejsu Unity
